gpuR2starMapping
=================

R2starMapping fits a single-compartment mono-exponential decay model (M0, R2*) to magnitude multi-echo GRE data. It is the simplest relaxometry model in GACELLE, with no diffusion, exchange, or fibre-geometry terms.

There is no single defining reference for this model; mono-exponential R2* decay fitting from multi-echo GRE magnitude data is a standard, long-established technique, not attributable to one paper. It is the R2* half of the same signal model used in the joint VFA-R1/R2* class (see :ref:`supportedmodels-JointR1R2star`), here fitted on its own.

Usage
^^^^^

.. code-block::

    obj = gpuR2starMapping(te);
    [out] = obj.estimate( data, mask, fitting);

I/O overview
^^^^^^^^^^^^

``obj = gpuR2starMapping(te);``

+---------------------------+--------------------------------------------------------------------------------------------------------------+
| Input                     | Description                                                                                                  |
+===========================+==============================================================================================================+
| te                        | 1xNte echo time [s]                                                                                          |
+---------------------------+--------------------------------------------------------------------------------------------------------------+

``[out] = obj.estimate( data, mask, fitting);``

.. note::
   ``estimate()`` here takes only ``(data, mask, fitting)`` - there is no ``extraData`` argument at all. The in-source docstrings for both ``estimate()`` and ``fit()`` describe a joint R1/R2* variable-flip-angle model with an ``extraData.b1`` input and a 5D ``[x,y,z,TE,FA]`` data array; this appears to be copied from ``gpuJointR1R2starMapping.m`` and does not match this class's actual signature or behaviour (confirmed against ``FWD()``, which only ever reads ``M0`` and ``R2star``, and against ``display_data_model_info()``, which correctly reports "R2* mapping with mGRE data"). The table below reflects what the code does, not the docstrings.

+---------------------------+--------------------------------------------------------------------------------------------------------------+
| Input                     | Description                                                                                                  |
+===========================+==============================================================================================================+
| data                      | 4D multi-echo GRE magnitude data, [x,y,z,te]                                                                 |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| mask                      | 3D mask, [x,y,z] (Optional; auto-generated by thresholding the first echo at 5% of its max if omitted)       |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fitting                   | Structure array for model parameter estimation (only class-specific options shown here)                      |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fitting.solver            | Solver used for estimation, 'askadam' (default) | 'mcmc'                                                     |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fitting.start             | Starting point method, 'prior' (default, closed-form) | 1xM parameters array                                 |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fitting.isWeighted        | Weight the cost by echo intensity, true | false (default = false)                                            |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fitting.weightMethod      | Weighting method, '1stecho' (default) | 'norm'                                                               |
+---------------------------+--------------------------------------------------------------------------------------------------------------+
| fitting.weightPower       | Power order of the weight (default = 2)                                                                      |
+---------------------------+--------------------------------------------------------------------------------------------------------------+

.. note::
   As of the 10 June 2026 update, ``gpuR2starMapping`` dispatches internally on ``fitting.solver``: the same object handles both the askAdam and MCMC solvers, and setting ``fitting.solver = 'mcmc'`` runs the MCMC path without needing a separate object.

``estimate()`` also runs GACELLE's automatic GPU memory manager (``utils.find_optimal_segment_3D``) transparently, segmenting large volumes if required. See `Automatic GPU Memory Management <https://gacelle.readthedocs.io/en/latest/advanced/automatic_memory_management.html>`_ for the relevant ``fitting.autoMemManage``, ``fitting.NSegmentUser``, and ``fitting.segmentOverlap`` options.
