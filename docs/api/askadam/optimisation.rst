askadam.optimisation
=====================

``optimisation()`` is GACELLE's Adam-based (or SGDM/RMSProp) gradient-descent parameter-estimation loop. Every GPU model class (``gpuNEXI``, ``gpuAxCaliberSMT``, etc.) calls ``askadam().optimisation(...)`` internally; this page documents that call directly, for anyone using it with a custom forward model outside the model-class framework. Other ``askadam`` methods are documented separately.

Usage
-----

.. code-block::

    out = askadam().optimisation( data, mask, weights, parameters, fitting, userfuncCell, varargin);

I/O overview
------------

+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Input        | Description                                                                                                                                                                                                                        |
+==============+====================================================================================================================================================================================================================================+
| data         | 2-D vectorised (measurement x voxel) or N-D (imaging) data. N-D input is reshaped internally via 'mask'.                                                                                                                           |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| mask         | (1-3)D signal mask. NOTE this mask does NOT apply to 'data' directly - it selects which voxels/columns are fitted.                                                                                                                 |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| weights      | N-D or 2-D weights, same shape convention as 'data' (Optional; defaults to ones)                                                                                                                                                   |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| parameters   | Structure of starting points for each model parameter (Optional; random/default init used if empty - see initialise_parameter)                                                                                                     |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting      | Structure of fitting algorithm parameters - see tables below                                                                                                                                                                       |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| userfuncCell | {FWDfunc} or {FWDfunc; REGfunc}: forward model handle, and optionally a custom regularisation handle. If REGfunc is omitted, the built-in spatial_total_variation regulariser is used with fitting.lambda/regmap/TVmode/voxelSize. |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| varargin     | {modelExtraArgs} or {modelExtraArgs; regExtraArgs}: extra positional arguments passed through to FWDfunc (and REGfunc, if supplied), after 'parameters'.                                                                           |
+--------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

.. note::
   ``userfuncCell`` and ``varargin`` both accept either a bare handle/cell (legacy, single forward-model form) or a 2-element cell pairing a forward model with a custom regulariser. When a custom ``REGfunc`` is supplied, ``fitting.defaultRegularisation`` is automatically set to ``false``, which suppresses the regmap/TVmode/voxelSize lines in ``display_basic_fitting_parameters``' output.

Parameter space transform
--------------------------

``fitting.parameterTransform`` controls how the bounded physical parameters are represented internally during gradient descent.

+---------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Mode                | Mechanism                                                                                                                                                                                                                                         | Notes                                                                                                                                                                                                                                                             |
+=====================+===================================================================================================================================================================================================================================================+===================================================================================================================================================================================================================================================================+
| 'sigmoid' (default) | Adam optimises an unconstrained z in (-inf, +inf); parameters are recovered as theta = lb + (ub-lb)*sigmoid(z). Starting points are logit-initialised (rescale01 then log-odds), clamped 1e-4*(ub-lb) away from the exact bounds to avoid +/-Inf. | No hard clamping is needed or applied during optimisation - sigmoid recovery guarantees theta stays in [lb,ub] by construction. Eliminates boundary-sticking, at the cost of a modified loss-surface geometry near the bounds.                                    |
+---------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 'linear'            | Adam optimises theta directly, rescaled to [0,1] via rescale01/unscale01. Starting points are rescale01(theta0) with optional uniform random perturbation.                                                                                        | Parameters are hard-clamped to [0,1] via set_boundary01 before optimisation, after every parameter update is implied by the transform, and again on the final and minimum-loss results after the loop. This is the original, fully backward-compatible behaviour. |
+---------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Both modes are implemented in ``unscale_parameters``/``rescale_parameters`` (dispatching on ``parameterTransform``) and rely on the lower-level ``rescale01``/``unscale01`` helpers - see Static utility methods below.

Stopping criteria
------------------

``askadam`` supports multiple stopping criteria that can be used independently or in combination.
The optimisation terminates when **any** active criterion is satisfied.

Basic stopping criteria
~~~~~~~~~~~~~~~~~~~~~~~~

These are always active.

+-----------------------------+------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Option                      | Default                                                                            | Description                                                                                                                                                                                           |
+=============================+====================================================================================+=======================================================================================================================================================================================================+
| fitting.iteration           | 4000 (docstring says 4000; check_set_default_basic code sets 1e4 - trust the code) | Stop when the maximum number of iterations is reached                                                                                                                                                 |
+-----------------------------+------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting.tol                 | 1e-3                                                                               | Stop when total loss falls below this threshold                                                                                                                                                       |
+-----------------------------+------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting.convergenceValue    | 1e-6                                                                               | Stop when the convergence signal falls below this threshold for patienceConvergence consecutive checks. NOTE: both the in-source docstring and earlier documentation stated 1e-8; the code sets 1e-6. |
+-----------------------------+------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting.patienceConvergence | 5 (= fitting.patience)                                                             | Number of consecutive checks below convergenceValue required before stopping                                                                                                                          |
+-----------------------------+------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting.patience            | 5                                                                                  | Shared default for all patience counters; individual patience* values override this                                                                                                                   |
+-----------------------------+------------------------------------------------------------------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Convergence model
~~~~~~~~~~~~~~~~~~

Controls how the convergence signal is computed from the loss. Applies to the loss-based stopping criterion above.

+---------------------------+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Option                    | Default | Description                                                                                                                                                                   |
+===========================+=========+===============================================================================================================================================================================+
| fitting.convergenceModel  | 'ema'   | 'linear': slope of loss over the last convergenceWindow iterations. 'ema': relative change in an exponential moving average of loss - more robust to short-term oscillations. |
+---------------------------+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting.convergenceWindow | 20      | Number of iterations used to compute the slope ('linear' model only)                                                                                                          |
+---------------------------+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| fitting.emaDecay          | 0.95    | EMA decay factor ('ema' model only); higher values smooth more aggressively                                                                                                   |
+---------------------------+---------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

Robust convergence
~~~~~~~~~~~~~~~~~~~

When enabled, detects voxels that are not improving relative to the rest of the population
and downweights their contribution to the gradient computation. The convergence signal is
then computed on the main (non-outlier) population only, preventing a small number of
stuck voxels from masking genuine convergence of the majority.

Outlier classification is based on two independent criteria, both of which must be satisfied
for a voxel to be flagged:

- **Criterion A**: the voxel has improved by less than ``outlierVoxelThres`` over the last
  ``outlierCheckWindow`` checks, while the median voxel has improved by more than ``outlierPopThres``.
- **Criterion B**: the voxel has improved by less than ``outlierInitThres`` relative to its
  own loss at initialisation, while the median voxel has improved by more than ``outlierInitPopThres``.

Once flagged, a voxel remains downweighted for at least ``outlierMinFlagDuration`` checks
before it can be reinstated, giving the downweighting time to take effect.

+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| Option                         | Default     | Description                                                                                  |
+================================+=============+==============================================================================================+
| fitting.robustConvergence      | false       | Enable outlier-aware gradient downweighting and main-population convergence checking         |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierThresholdMethod | 'behaviour' | Placeholder for future threshold-selection methods; currently has no alternative implemented |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierWeight          | 0.1         | Gradient contribution of outlier voxels relative to main population (0-1)                    |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.weightUpdateInterval   | 5           | Number of iterations between outlier mask and weight updates                                 |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierCheckWindow     | 5           | Number of checks used to assess improvement in criterion A                                   |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierMinFlagDuration | 5           | Minimum number of checks a voxel remains flagged before reassessment                         |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierVoxelThres      | 0.01        | Criterion A: minimum fractional improvement required per voxel (1%)                          |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierPopThres        | 0.05        | Criterion A: minimum fractional improvement required for median voxel (5%)                   |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierInitThres       | 0.05        | Criterion B: minimum fractional improvement from initialisation per voxel (5%)               |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+
| fitting.outlierInitPopThres    | 0.20        | Criterion B: minimum fractional improvement from initialisation for median (20%)             |
+--------------------------------+-------------+----------------------------------------------------------------------------------------------+

.. note::

    Outlier downweighting applies to the data fidelity gradient only. TV regularisation
    gradients are unaffected. The outlier classification lags by one ``weightUpdateInterval``
    because ``extractdata`` breaks the autodiff graph - this is intentional.

Additional convergence signals
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

These optional signals provide additional stopping criteria independent of ``robustConvergence``.
Each uses the same ``patience`` mechanism as the loss-based criterion.

.. warning::

    Both signals default to ``1e-6``, not ``0``. **They are active by default**, not opt-in -
    this corrects earlier documentation, which stated both defaulted to ``0`` (disabled). A
    value of ``0`` does disable a signal (both the stopping check and the corresponding lines
    in ``display_basic_fitting_parameters`` are gated on ``> 0``), but that is not what a fresh
    ``fitting`` struct actually gets from ``check_set_default_basic``.

**Step norm** (analogous to ``StepTolerance`` in ``lsqnonlin``):

Stops when the relative norm of the parameter update step falls below threshold,
indicating that parameters have effectively stopped moving:

.. math::

    \frac{\| \Delta\theta \|_2}{1 + \| \theta \|_2} < \texttt{convergenceStepTol}

**Gradient norm**:

Stops when the raw gradient norm (before Adam correction) falls below threshold,
indicating that the loss landscape is genuinely flat.

+----------------------------+------------------------+--------------------------------------------------------------------------------------------------+
| Option                     | Default                | Description                                                                                      |
+============================+========================+==================================================================================================+
| fitting.convergenceStepTol | 1e-6                   | Relative step-norm threshold. NOTE: this is active by default, not disabled - see warning below. |
+----------------------------+------------------------+--------------------------------------------------------------------------------------------------+
| fitting.patienceStep       | 5 (= fitting.patience) | Consecutive checks below threshold required before stopping                                      |
+----------------------------+------------------------+--------------------------------------------------------------------------------------------------+
| fitting.convergenceGradTol | 1e-6                   | Gradient-norm threshold. NOTE: this is active by default, not disabled - see warning below.      |
+----------------------------+------------------------+--------------------------------------------------------------------------------------------------+
| fitting.patienceGrad       | 5 (= fitting.patience) | Consecutive checks below threshold required before stopping                                      |
+----------------------------+------------------------+--------------------------------------------------------------------------------------------------+

.. note::

    The step norm and gradient norm signals are complementary. The step norm catches
    parameter stagnation; the gradient norm catches loss landscape flatness. With Adam,
    a small step norm does not necessarily imply a small gradient norm since Adam
    normalises gradients via its second moment estimate.

Example: enabling robust convergence with EMA
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: matlab

    fitting.convergenceModel    = 'ema';       % use EMA-smoothed convergence signal (also the default)
    fitting.robustConvergence   = true;        % enable outlier-aware convergence
    fitting.outlierWeight       = 0.1;         % outlier voxels contribute 10% gradient weight
    fitting.weightUpdateInterval = 5;          % update outlier mask every 5 iterations

    obj = askadam;
    out = obj.optimisation(data, mask, weights, parameters, fitting, FWDfunc, varargin);
